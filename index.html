Deployment & Integration Guide

1
Deploy via Express, GitHub Pages, or CDN
Run node server.js (Express / HTTP with CORS enabled) or push to a GitHub repository and turn on GitHub Pages in Settings > Pages. 
# Start local server with CORS support
node server.js
# Output: Serving on http://localhost:3000/orbital-loader.js
2
Include in Any Webpage
Add the single script tag to your HTML header or before </body>. No external CSS stylesheet is required. 
<script src="https://your-domain.com/orbital-loader.js"></script>
3
Call or Declare the Component
Use utility classes, custom element, or the programmatic JavaScript API: 
<!-- Option A: Utility Class with HTML attributes -->
<div class="orbital-loader size-md" data-speed="1.2"></div>

<!-- Option B: Web Component -->
<orbital-loader size="64" speed="1.2" mode="kinetic"></orbital-loader>

<!-- Option C: JavaScript API -->
<script>
  const loader = OrbitalLoader.create('#my-container', { size: 64, speed: 1.2 });
</script>
